# 💎 NEXUS Finance — Aplicación Web Next.js 16

Aplicación principal de **NEXUS Finance**, desarrollada con **Next.js 16 (App Router + Turbopack)**, **TypeScript** estricto y **Tailwind CSS**.

---

## 🚀 Comandos Rápidos

```bash
# Instalar dependencias
npm install

# Modo desarrollo
npm run dev

# Verificación de tipos TypeScript estricto (0 errores)
npx tsc --noEmit

# Compilación de producción
npm run build

# Ejecutar suite de validación de producción
npx tsx scripts/verify-production-readiness.mjs
```
